# Ясно

Схемы бизнес-процессов за несколько минут. Шаблон или обычный текст превращается в flowchart: этапы, решения, узкие места, точки автоматизации и экспорт в PNG.

Процессы перестают жить только в головах сотрудников.

## Запуск

Нужен Node.js 22 или новее.

```bash
npm install
npm run dev
```

- Сайт: http://127.0.0.1:5173/
- API: http://127.0.0.1:8787/

`npm run dev` поднимает оба процесса. Фронтенд проксирует запросы `/api` на сервер.

База — файл `data/yasno.sqlite`. Папка `data` в git не попадает.

## Что есть

- Семь шаблонов: продажи, онбординг, поддержка, заказ, закупка, жалоба, запуск продукта.
- Текст своими словами: строка — этап, вопрос — решение, через `|` можно указать время и роль.
- Редактор на React Flow: блоки, стрелки, перетаскивание, ответственный, время, отмена.
- Метки «узкое место» и «точка автоматизации» с комментарием. Они видны на схеме и попадают в PNG.
- Аккаунт по почте и паролю. Пароль хранится как хеш, сессия — в httpOnly-куке.
- Гостевая сессия: схемы уже на сервере и привязываются к почте после регистрации.
- Free — 3 процесса и отметка на PNG. Pro снимает лимит, убирает отметку и открывает публичную ссылку `/p/…`.
- Светлая и тёмная тема.

Оплаты нет: кнопка Pro только записывает тариф в базу.

## Скрипты

| Команда | Что делает |
| --- | --- |
| `npm run dev` | API и сайт вместе |
| `npm run server` | Только API |
| `npm run build` | Проверка типов и сборка фронтенда |
| `npm run lint` | Oxlint |
| `npm run preview` | Собранный фронтенд |

## Стек

- Фронтенд: React, TypeScript, Vite, Tailwind CSS, React Flow
- Бэкенд: Express, SQLite (`node:sqlite`)
